# ATLAS Metrics

The **Metrics** folder contains progress reports for the ATLAS repository.

Unlike Registries, which record what exists, Metrics track the growth, milestones, and overall progress of the repository over time.

These reports provide a high-level overview of documentation progress and help measure the evolution of the research.

---

# Metrics Overview

## Human Friction Metrics

Tracks the overall progress of Human Friction documentation.

This report includes:

- Repository progress
- Documentation milestones
- Category progress
- Repository records
- Daily progress
- Next milestones

It serves as the primary progress dashboard for Human Friction research.

---

## Pattern Metrics

Tracks the overall progress of Pattern discovery and validation.

This report includes:

- Pattern documentation progress
- Candidate and Accepted Patterns
- Validation progress
- Supporting Human Friction coverage
- Pattern milestones

It provides an overview of behavioural pattern research within ATLAS.

---

# Guiding Principles

Metrics measure repository progress—they do not contain research findings.

They should be updated whenever meaningful progress is made, allowing contributors to monitor repository growth, celebrate milestones, and identify future objectives.
