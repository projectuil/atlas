# ATLAS Templates

The **Templates** folder contains the official document templates used throughout the ATLAS repository.

Each template defines the standard structure, metadata, and documentation format for a specific type of research document. Using these templates ensures consistency, readability, and long-term maintainability across the repository.

Every new document created in ATLAS should be based on the appropriate template.

---

# Templates Overview

## 01 – Human Friction Template

The standard template for documenting individual Human Frictions.

Used to record:

- Metadata
- Problem
- Human Impact
- Context
- Evidence / Observation
- Research Notes
- Revision History

Every Human Friction documented in ATLAS should follow this template.

---

## 02 – Pattern Template

The standard template for documenting recurring behavioural patterns identified across multiple Human Frictions.

Used to record:

- Pattern Metadata
- Pattern Description
- Human Impact
- Supporting Evidence
- Research Notes
- Revision History

Patterns are derived from evidence and should be supported by multiple Human Frictions.

---

## 03 – Research Insight Template

The standard template for documenting research insights discovered during analysis.

Research Insights represent validated observations, conclusions, or findings that emerge from Human Frictions, Patterns, or Research Papers.

Each insight should be documented using this template.

---

## 04 – Research Paper Template

The standard template for writing formal research papers within ATLAS.

Used to organize:

- Research Metadata
- Abstract
- Introduction
- Literature Review
- Methodology
- Findings
- Discussion
- Conclusion
- References

Research Papers synthesize evidence from Human Frictions, Patterns, and Research Insights into comprehensive studies.

---

# Template Usage

When creating a new document:

1. Select the appropriate template.
2. Create a copy of the template.
3. Rename the document according to the Naming Convention.
4. Replace all placeholder content with validated research.
5. Save the completed document in its appropriate repository folder.

---

# Guiding Principles

Templates define **how information should be documented**, not **what information should be documented**.

Any changes to these templates should improve documentation quality while maintaining consistency across the ATLAS repository.
