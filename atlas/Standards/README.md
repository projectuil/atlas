# ATLAS Standards

The **Standards** folder contains the official rules, conventions, and documentation standards that govern the ATLAS repository.

These documents ensure that every Human Friction, Pattern, Research Insight, and Research Paper follows a consistent structure, naming convention, and classification system. They define **how information should be documented**, not the information itself.

All contributors should review these standards before creating or modifying repository content.

---

# Standards Overview

## 01 – Category Classification

Defines the official ATLAS taxonomy used to organize Human Frictions.

This document explains:

- Category hierarchy
- Category identifiers
- Category prefixes
- Classification rules
- Category relationships

Example:

- FF – Files & Project Management
- OS – Operating System
- KI – Keyboard & Input

---

## 02 – APID Standard

Defines the Atlas Problem Identifier (APID) system.

This document explains:

- APID format
- Numbering conventions
- Prefix usage
- Identifier uniqueness
- APID assignment rules

Example:

- FF-001
- OS-014
- KI-026

---

## 03 – Naming Convention

Defines standardized naming rules used throughout the repository.

This document explains:

- Document names
- Human Friction titles
- Pattern names
- Registry naming
- Folder naming
- File naming conventions

The goal is to maintain consistency across the entire repository.

---

## 04 – Relationship Model

Defines how different repository components relate to one another.

This document explains relationships between:

- Human Frictions
- Patterns
- Research Insights
- Research Papers
- Categories
- Registries

It describes the overall knowledge structure of ATLAS.

---

## 05 – Validation Classification

Defines the evidence and validation levels used within ATLAS.

This document explains:

- Observation Levels
- Confidence Levels
- Validation Status
- Acceptance criteria
- Research maturity

These standards ensure observations are evaluated consistently.

---

## 06 – Tagging Standard

Defines the tagging system used across the repository.

This document explains:

- Tag creation
- Tag formatting
- Tag consistency
- Search optimization
- Cross-document discoverability

Tags improve organization and information retrieval.

---

## 07 – Versioning and Governance

Defines repository maintenance and document lifecycle policies.

This document explains:

- Version numbering
- Revision history
- Document updates
- Repository governance
- Change management

These standards ensure long-term consistency as the repository evolves.

---

# Guiding Principles

The Standards folder is intended to remain stable over time.

Repository growth should occur through the creation of new Human Frictions, Patterns, Research Insights, and Research Papers—not through frequent changes to these standards.

Changes to these documents should only be made when they improve the overall structure, consistency, or maintainability of the ATLAS repository.
