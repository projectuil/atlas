# Repository Purpose

The Pattern Repository captures recurring behaviors, structures, and underlying mechanisms observed across multiple Human Frictions. Unlike Human Frictions, which describe individual user problems, Patterns identify common characteristics shared by many Human Frictions.

Patterns serve as reusable research knowledge that helps explain why different Human Frictions emerge and how they are connected.
