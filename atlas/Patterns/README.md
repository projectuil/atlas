# ATLAS Patterns

The **Patterns** folder contains documented behavioural patterns discovered through the analysis of multiple Human Frictions.

Unlike Human Frictions, which document individual observed problems, Patterns represent recurring relationships, behaviours, or phenomena that consistently appear across multiple observations.

Patterns help transform isolated observations into broader research knowledge.

---

# Purpose

The purpose of this folder is to:

- Identify recurring behavioural patterns.
- Explain relationships between Human Frictions.
- Build reusable research knowledge.
- Provide evidence for future Research Insights and Research Papers.

Every Pattern should be supported by multiple validated Human Frictions.

---

# Pattern Structure

Each Pattern is documented as an individual document using the official Pattern Template.

A typical Pattern includes:

- Pattern Metadata
- Pattern Description
- Human Impact
- Supporting Evidence
- Research Notes
- Revision History

---

# Relationship to Human Frictions

Human Frictions describe **individual observed problems**.

Patterns describe **the recurring behaviour shared by multiple Human Frictions**.

Example:

Human Frictions

- FF-001 — Downloaded files are difficult to find after downloading.
- FF-002 — Large collections of files become difficult to understand.
- FF-003 — Users forget file and folder names over time.
- FF-004 — Large software projects become difficult to navigate.

↓

Pattern

- PAT-001 — Context Loss Over Time

The Pattern explains the common behavioural relationship connecting these observations.

---

# Pattern Validation

Patterns should never be created from assumptions.

Each Pattern should:

- Be supported by multiple Human Frictions.
- Be based on observed evidence.
- Be continuously refined as new evidence becomes available.
- Be upgraded in confidence only after sufficient validation.

---

# Guiding Principles

Patterns are discoveries, not hypotheses.

They should emerge naturally from repeated observations documented throughout the ATLAS repository.

Every Pattern should strengthen the overall understanding of human behaviour without duplicating the information contained in individual Human Frictions.
