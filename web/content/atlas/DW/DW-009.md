Users frequently set up quick window arrangements for temporary tasks (e.g., answering a quick call, verifying a invoice). Operating systems treat these temporary window states identically to long-term primary project workspaces. Over time, ad-hoc temporary windows clutter the primary workspace, making it difficult to distinguish core active work from disposable sessions.

**Human Impact**

*   Digital clutter accumulation.
*   Difficulty identifying core project boundaries.
*   Reluctance to close windows out of fear of losing necessary temporary data.

**Context**

Commonly occurs when:

*   Handling quick interruptions during long-term focused work.
*   Opening temporary files or reference tabs during a meeting.

**Evidence / Observation**

Temporary windows opened for a 2-minute lookup often remain open alongside primary project windows for days because the OS provides no lifecycle distinction for short-term vs. long-term workspaces.

**Research Notes**

*   Introduces the concept of workspace lifecycle and intent preservation.
