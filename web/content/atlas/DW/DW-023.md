Users perform many recurring daily routines that demand identical application arrangements (e.g., a weekly team sync layout with Zoom on the left, agenda on the right, chat on bottom). OS environments rarely allow users to save or trigger these multi-application spatial layouts as reusable workspace templates, requiring manual setup every time.

**Human Impact**

*   Repetitive manual setup effort for routine tasks.
*   Inconsistent working setups across recurring task instances.
*   Time lost before starting scheduled recurring work.

**Context**

Commonly occurs when:

*   Starting weekly meetings, recurring development sessions, or daily reporting routines.

**Evidence / Observation**

Users manually open the exact same 3 apps and drag them into identical screen positions every Monday morning or at the start of specific recurring meetings.

**Research Notes**

*   Connects to workspace layout automation and preset state restoration.
