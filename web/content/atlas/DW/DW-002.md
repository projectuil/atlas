Virtual desktops allow users to segment their work into separate logical spaces. However, as the number of virtual desktops increases, users struggle to track which applications or projects reside on which virtual display. Without continuous persistent spatial cues, users spend effort cycling back and forth through virtual spaces, defeating the spatial organization purpose.

**Human Impact**

*   Spatial confusion and lost orientation across virtual environments.
*   Increased reliance on human memory to remember virtual desktop contents.
*   Frustration when applications open on unexpected virtual screens.

**Context**

Commonly occurs when:

*   Creating 3 or more virtual desktops for different tasks.
*   Moving between personal, development, and administrative tasks.
*   Returning to virtual desktops after taking breaks or completing meetings.

**Evidence / Observation**

Users frequently switch across virtual desktops using keyboard shortcuts or trackpad gestures without remembering where a specific application lives, leading to a trial-and-error cycle of scanning every virtual screen until the application is found.

**Research Notes**

*   Highlights the limitation of non-visual spatial abstractions in human-computer interfaces.
*   Connects to spatial memory and context loss research.
