In multi-window layouts, subtle visual differences between active and inactive windows (e.g., slight title bar color shifts) fail to clearly communicate active input focus. Users routinely begin typing keyboard shortcuts or text strings assuming one application is active, only to discover input went into a background window or lost focus entirely.

**Human Impact**

*   Erroneous keystrokes and unintended actions in background apps.
*   Frustration when typed text fails to appear where intended.
*   Loss of speed during rapid keyboard-driven workflows.

**Context**

Commonly occurs when:

*   Working across multiple visible tiled or side-by-side windows.
*   Using keyboard shortcuts (Cmd+Tab / Alt+Tab) rapidly.

**Evidence / Observation**

Users frequently type complete sentences or execute keyboard shortcuts before realizing focus was active on a different window, requiring deletion and re-entry.

**Research Notes**

*   Directly addresses active UI state feedback and focus indicators.
