Operating systems group windows by application type (e.g., all browser windows together, all PDFs together) rather than by human task objectives. Users performing a specific task (e.g., "Prepare Monthly Tax Return") must manually tie together specific tabs, spreadsheets, and folders scattered across different application groups.

**Human Impact**

*   High mental load needed to maintain connections between related task files.
*   Difficulty switching cleanly between different active projects.
*   Fragmented task organization.

**Context**

Commonly occurs when:

*   Working on multiple distinct projects concurrently during a single workday.
*   Combining diverse media types (PDFs, URLs, spreadsheets) for a single goal.

**Evidence / Observation**

Users regularly express desire to "group this browser tab with this specific spreadsheet," but are constrained by OS structures that mandate application-first grouping.

**Research Notes**

*   Highlights the clash between application-centric OS architectures and human goal-oriented workflows.
