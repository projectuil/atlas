Applications often recall previous screen coordinates and launch off-screen or on powered-off/secondary monitors. When a user launches an application, no visual window appears on their primary display, leading them to believe the application failed to start or is missing.

**Human Impact**

*   Confusion and disruption upon launching applications.
*   Time spent troubleshooting unresponsive or "invisible" application launches.
*   Need to use advanced key combinations to drag off-screen windows back into view.

**Context**

Commonly occurs when:

*   Disconnecting external monitors from a laptop.
*   Launching secondary windows or pop-ups in multi-display configurations.

**Evidence / Observation**

Users repeatedly click application icons assuming they didn't open, unaware the window opened on an inactive or turned-off secondary display.

**Research Notes**

*   Focuses on display state synchronization bugs and window spawning algorithms.
