As a task evolves in scope (e.g., transitioning from simple reading to intensive multi-document writing and data editing), the ideal desktop organization changes. Desktop environments lack flexible layout structures that adapt smoothly to shifting task scope, forcing users to manually tear down and rebuild layouts as requirements change.

**Human Impact**

*   Resistance to adapting workspace setups to better suit changing task needs.
*   Sub-optimal working configurations prolonged past their usefulness.
*   Constant manual effort to re-align windows as task complexity expands.

**Context**

Commonly occurs when:

*   An initial short lookup task expands into a multi-hour deep analysis project.
*   Collaborative tasks transition into independent authoring phases.

**Evidence / Observation**

Users routinely stay in cramped or outdated window configurations long after a task has outgrown them because reconfiguring the screen requires too much manual effort.

**Research Notes**

*   Demonstrates the friction between static layout mechanics and dynamic task evolution.
