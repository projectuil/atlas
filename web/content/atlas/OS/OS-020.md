Users often struggle to understand how hardware and software depend on one another to function correctly. Many assume that installing software alone guarantees functionality, without recognizing the role of compatible hardware, device drivers, firmware, and operating system support. This misunderstanding creates confusion when applications or devices fail to operate as expected.

**Human Impact**

*   Difficulty diagnosing compatibility issues.
*   Incorrect assumptions about software capabilities.
*   Frustration when devices fail to function.
*   Increased dependence on technical assistance.
*   Reduced confidence understanding system behaviour.

**Context**

Commonly occurs when:

*   Installing printers or scanners.
*   Connecting external hardware.
*   Installing device drivers.
*   Upgrading hardware.
*   Running hardware-dependent applications.

**Evidence / Observation**

This behaviour is consistently observed across desktop operating systems. Users frequently ask questions such as **"Why doesn't my printer work?"**, **"Why can't the software detect my device?"**, or **"Do I need to install a driver?"** Because the relationship between hardware, drivers, the operating system, and applications is largely invisible, users often perceive failures as isolated problems rather than dependency issues.

**Research Notes**

*   Introduces the interaction between hardware and software.
*   Expands the user's operating system mental model beyond software alone.
*   Frequently observed during hardware installation and upgrades.
*   Likely contributes to future behavioural patterns related to **System Dependency Awareness**.
