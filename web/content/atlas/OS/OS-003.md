Users often struggle to remember where operating system settings are located. Although settings are grouped into categories, many configuration options are distributed across multiple menus, search interfaces, and control panels. As a result, users frequently rely on memory, internet searches, or repeated navigation to locate settings they have previously used.

**Human Impact**

*   Time lost searching for settings.
*   Interrupted workflow.
*   Increased cognitive load.
*   Dependence on online tutorials.
*   Reduced confidence when configuring the operating system.

**Context**

Commonly occurs when:

*   Connecting to Wi-Fi.
*   Changing display settings.
*   Managing storage.
*   Configuring privacy or security options.
*   Troubleshooting system problems.

**Evidence / Observation**

This behaviour is repeatedly observed across Windows, macOS, and Linux operating systems. Users frequently remember that a particular setting exists but cannot recall its location within the system. Questions such as _"Where is Device Manager?"_, _"Where do I change display scaling?"_, or _"Where are privacy settings?"_ are common. As operating systems continue to expand, the number of available configuration options increases, making navigation more dependent on memory than recognition.
