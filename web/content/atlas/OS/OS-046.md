Modern digital work is distributed across applications, files, cloud services, communication platforms, browsers, and external devices. Operating systems manage each of these components independently but possess no unified representation of the user's overall work. Consequently, users must mentally integrate information from multiple disconnected environments while the operating system manages only individual resources rather than the complete digital activity.

**Human Impact**

*   Fragmented digital experiences.
*   Increased cognitive workload.
*   Slower information retrieval.
*   Difficulty maintaining situational awareness.
*   Reduced efficiency during complex projects.

**Context**

Commonly occurs when:

*   Managing enterprise projects.
*   Conducting cybersecurity investigations.
*   Academic research.
*   Software engineering.
*   Cross-platform collaboration.

**Evidence / Observation**

A single work activity may involve local files, cloud storage, web applications, communication platforms, development tools, documentation, and external devices. Although all of these contribute to one objective, operating systems maintain separate representations for each component. Users therefore become the primary mechanism responsible for integrating their digital environment into a coherent workflow.

**Research Notes**

*   Identifies the absence of a unified work model within current operating systems.
*   Extends previous Human Frictions concerning task context, project management, and user intent.
*   Establishes a research foundation for operating systems capable of representing and managing work as an interconnected ecosystem rather than isolated applications and resources.
