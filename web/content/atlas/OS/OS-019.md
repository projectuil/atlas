Users often struggle to determine whether a problem originates from the operating system or from a specific application. Since both can produce similar symptoms, such as freezing, crashes, slow performance, or error messages, users frequently attribute the issue to the wrong source. This misunderstanding leads to ineffective troubleshooting and unnecessary corrective actions.

**Human Impact**

*   Incorrect troubleshooting decisions.
*   Unnecessary software reinstallation.
*   Time lost investigating unrelated causes.
*   Increased frustration.
*   Greater dependence on technical support.

**Context**

Commonly occurs when:

*   Applications crash repeatedly.
*   The computer becomes slow.
*   Error messages appear.
*   Devices stop functioning correctly.
*   Performing system maintenance.

**Evidence / Observation**

This behaviour is consistently observed among desktop users. Questions such as **"Is Windows broken or is the application broken?"**, **"Should I reinstall the operating system?"**, or **"Is this software causing the problem?"** are common because users lack a mental model that separates application behaviour from operating system functionality.
