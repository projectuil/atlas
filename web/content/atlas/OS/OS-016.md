Users often struggle to understand how memory (RAM) is used by the operating system and running applications. Many users confuse RAM with storage or assume that unused RAM is wasted. Without understanding the temporary nature of memory usage, users find it difficult to interpret performance information or identify memory-related problems.

**Human Impact**

*   Misinterpretation of system performance.
*   Incorrect assumptions about memory usage.
*   Unnecessary concern when RAM utilization appears high.
*   Difficulty troubleshooting performance issues.
*   Increased dependence on technical guidance.

**Context**

Commonly occurs when:

*   Monitoring Task Manager or System Monitor.
*   Running multiple applications.
*   Comparing computer specifications.
*   Troubleshooting slow performance.
*   Purchasing or upgrading computers.

**Evidence / Observation**

This behaviour is consistently observed across desktop operating systems. Users frequently ask questions such as **"Why is my RAM always full?"**, **"Is RAM the same as storage?"**, or **"Should I close applications to free memory?"** Although operating systems display memory statistics, they rarely explain how memory is allocated, cached, or released during normal operation.

**Research Notes**

*   Focuses on conceptual understanding of volatile memory.
*   Complements OS-014 (performance) and OS-015 (storage).
*   Frequently observed when users begin monitoring system resources.
*   Likely contributes to future behavioural patterns related to **Resource Awareness**.
