Users often struggle to understand why different file types automatically open with specific applications. They may not realize that operating systems maintain file associations linking file extensions to default software. Consequently, users become confused when files open with unexpected applications or fail to open correctly.

**Human Impact**

*   Confusion while opening files.
*   Delayed task completion.
*   Incorrect application usage.
*   Increased reliance on technical support.
*   Reduced confidence managing files.

**Context**

Commonly occurs when:

*   Opening unfamiliar file types.
*   Installing new software.
*   Changing default applications.
*   Sharing files between computers.
*   Working with multiple applications supporting the same format.

**Evidence / Observation**

This behaviour is frequently observed when users encounter unfamiliar file extensions or install new software that changes default applications. Questions such as **"Why does this file open in this application?"** or **"How do I change the default program?"** commonly arise because file associations operate automatically with little explanation from the operating system.

**Research Notes**

*   Bridges operating system concepts with file management.
*   Focuses on relationships between files and applications.
*   Frequently observed after software installation or migration.
*   Likely contributes to future behavioural patterns related to **Application Relationships**.
