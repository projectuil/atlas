Operating systems include numerous built-in applications and utilities, but users often struggle to understand their individual purposes. Applications such as File Explorer, Terminal, Task Manager, Settings, Control Panel, Disk Management, and Device Manager are visible within the system, yet many users do not know when or why they should use them. As a result, important operating system functionality remains underutilized.

**Human Impact**

*   Difficulty understanding operating system capabilities.
*   Increased reliance on external assistance.
*   Slower problem solving.
*   Reduced confidence while using the computer.
*   Limited use of built-in system tools.

**Context**

Commonly occurs when:

*   Learning a new operating system.
*   Troubleshooting system problems.
*   Exploring system menus.
*   Following online tutorials.
*   Performing administrative tasks.

**Evidence / Observation**

This behaviour is consistently observed among beginner and intermediate users. Many users recognize the names of built-in utilities but cannot explain their purpose or identify situations in which they should be used. As operating systems continue to include more specialized system applications, distinguishing their roles becomes increasingly difficult without prior knowledge or guidance.

**Research Notes**

*   Builds upon understanding of operating system fundamentals.
*   Focuses on recognizing system functionality rather than application usage.
*   Highlights the gap between feature availability and user understanding.
*   Likely contributes to future behavioural patterns related to **System Discoverability**.
