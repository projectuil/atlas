After successfully installing software, users often struggle to locate the application. They may expect the application to appear on the desktop, in the Downloads folder, or in the same location as the installer. Because operating systems provide multiple ways to access installed software, users frequently become uncertain about where applications are stored and how they should be launched.

**Human Impact**

*   Time lost searching for installed applications.
*   Confusion after successful installation.
*   Repeated installation attempts.
*   Interrupted workflow.
*   Reduced confidence using the operating system.

**Context**

Commonly occurs when:

*   Installing software for the first time.
*   Using unfamiliar operating systems.
*   Setting up a new computer.
*   Installing applications from downloaded installers.
*   Learning desktop environments.

**Evidence / Observation**

This behaviour is commonly observed after software installation. Users frequently ask questions such as **"Where did my application go?"**, **"Why isn't it on my desktop?"**, or **"Did the installation actually finish?"** Operating systems often create shortcuts in different locations depending on installation settings, making application discovery dependent on prior knowledge.
