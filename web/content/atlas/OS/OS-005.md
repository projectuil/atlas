Users often know what they want to accomplish but struggle to determine which application should be used to perform the task. Since multiple applications may appear capable of performing similar functions, users become uncertain about which software is appropriate, resulting in delays and unnecessary experimentation.

**Human Impact**

*   Delayed task completion.
*   Increased uncertainty.
*   Trial-and-error application usage.
*   Reduced productivity.
*   Greater dependence on internet searches or external guidance.

**Context**

Commonly occurs when:

*   Editing documents.
*   Compressing files.
*   Viewing unfamiliar file types.
*   Creating presentations.
*   Performing system maintenance.

**Evidence / Observation**

This behaviour is commonly observed across desktop operating systems. Users frequently ask questions such as _"Which application opens this file?"_, _"What software should I use for this?"_, or _"Do I need to install something?"_ Although operating systems provide access to many applications, they rarely explain which application best matches a user's intended task.

**Research Notes**

*   Focuses on task-to-application mapping.
*   Differs from OS-004 by emphasizing application selection rather than understanding application purpose.
*   Represents an early decision-making challenge during operating system use.
*   Likely contributes to future behavioural patterns related to **Application Discovery**.
