.


Tasks requiring interdisciplinary integration (e.g., combining UI design, backend logic, and database management) multiply cognitive strain, confusing where problem resolution belongs.

**Human Impact**

*   Context switching exhaustion and cognitive overload.
*   Confusion regarding which specific domain layer caused an issue.
*   Feeling underprepared for multi-disciplinary responsibilities.

**Context**

Commonly occurs when:

*   Building full-stack software applications for the first time.
*   Learning data science (combining statistics, domain logic, and programming).

**Evidence / Observation**

Beginners attempting full-stack projects frequently get overwhelmed because they cannot isolate whether a bug resides in the database query, API route, or frontend logic.

**Research Notes**

*   Emphasizes isolating variables and domain layers during early learning modules.
