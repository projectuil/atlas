Mixing letters, numbers, and special symbols in a single input string breaks cadence. Moving between the primary alpha row, the top number row, and Shift key combinations forces speed slowdowns and cadence disruption.

**Human Impact**

*   Noticeable slowdown when typing passwords, formulas, code, or mixed data.
*   Elevated mistake frequency on numerical and symbol characters.
*   Fatigue from continuous finger stretching across keyboard tiers.

**Context**

Commonly occurs when:

*   Entering strong passwords with complex requirements.
*   Writing mathematical expressions, code parameters, or physical addresses.

**Evidence / Observation**

Inter-keystroke interval (IKI) data shows sharp spikes in latency when users transition from alphabetic sequences to shifted number-row symbols.

**Research Notes**

*   Underpins research into contextual input layers and smart input auto-formatting.
