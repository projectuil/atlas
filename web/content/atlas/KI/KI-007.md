Human procedural memory requires regular reinforcement to maintain motor skills and shortcut association. When a keyboard shortcut is executed infrequently (e.g., inserting a table, opening advanced settings, or triggering specialized application macros), users fail to retain the key binding, making the shortcut effectively useless for saving time.

**Human Impact**

*   Abandonment of efficiency features in favor of slow menu navigation.
*   Repeated necessity to look up key bindings in documentation or help menus.
*   Inconsistent productivity across varying application tasks.

**Context**

Commonly occurs when:

*   Executing periodic administrative tasks.
*   Performing occasional formatting operations in publishing software.
*   Utilizing specialized tools within IDEs or media creation suites.

**Evidence / Observation**

Cognitive retention decay curves show steep decline for arbitrary key combinations when not executed daily. Users frequently comment that attempting to guess rarely used shortcuts results in unexpected side effects or error dialogs.

**Research Notes**

*   Extends KI-003 by analyzing the decay rate of non-routine procedural interactions.
*   Foundation for context-aware shortcut prompts and dynamic command palettes.
