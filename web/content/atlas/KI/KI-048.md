Fundamental keys operate differently in development tools and terminals compared to standard GUI applications (e.g., Ctrl+C sends SIGINT signal in terminals rather than copying text; Tab inserts spaces in IDEs but triggers auto-completion in shells).

**Human Impact**

*   Disruption when transitioning between terminal command lines and standard GUI apps.
*   Accidental termination of running processes when attempting to copy text in terminals.
*   Confusion regarding environmental context boundaries.

**Context**

Commonly occurs when:

*   Software developers working simultaneously in terminal shells and web browsers.
*   System administrators executing remote commands via SSH.

**Evidence / Observation**

Unintended SIGINT process cancellations caused by pressing Ctrl+C to copy terminal output remain one of the top reported terminal usability complaints across platforms.

**Research Notes**

*   Addresses legacy terminal architecture collisions with modern desktop conventions.
