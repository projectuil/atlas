While entering body text, automatic formatting features (such as auto-capitalization, smart quotes, automatic bullet list generation, or automatic indentation) frequently trigger unintentionally. Users feel compelled to stop writing immediately to fix the auto-formatting anomaly before continuing text composition.

**Human Impact**

*   Repeated disruption of creative thought flow during writing.
*   Time wasted struggling against aggressive software auto-formatting rules.
*   Frustration when formatting rules override intentional plain-text input.

**Context**

Commonly occurs when:

*   Composing structured documents in Microsoft Word, Google Docs, or Notion.
*   Writing code or configuration files in basic text editors that enforce smart quotes.
*   Typing lists containing specific numbering schemes.

**Evidence / Observation**

Writing behavior studies show that users spend a disproportionate amount of time repairing unintended auto-formatting changes compared to repairing actual spelling errors.

**Research Notes**

*   Examines friction caused by over-eager intelligent input processing.
*   Supports plain-text-first and explicit Markdown formatting paradigms.
