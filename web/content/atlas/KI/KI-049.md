As software platforms add features, shortcut combinations become increasingly complex, requiring 3- or 4-key modifier chords or obscure sequences. The cognitive effort required to remember these bloated shortcut systems eventually exceeds the effort of using visual menus.

**Human Impact**

*   Abandonment of keyboard navigation in complex software.
*   Perception of modern software as overly convoluted.
*   Shortcut collisions where newly added features hijack established keybindings.

**Context**

Commonly occurs when:

*   Software suites undergo major updates that add dozens of new feature keybindings.
*   Enterprise platforms expand beyond their original core feature set.

**Evidence / Observation**

User feedback logs show sharp declines in keybinding usage metrics after application updates introduce multi-modifier shortcuts for core features.

**Research Notes**

*   Explores cognitive saturation points in keyboard interaction design.
