While global shortcuts like Copy and Paste are standard, application-specific shortcuts vary wildly across different programs. For example, clearing lines, toggling developer tools, searching, or duplicating elements use entirely different key combinations across different web browsers, vector tools, code editors, and office suites, causing cognitive interference.

**Human Impact**

*   Muscle memory interference when switching between different applications.
*   Higher rates of accidental action execution due to applying one program's shortcuts in another.
*   Mental strain associated with maintaining separate hotkey dictionaries per application.

**Context**

Commonly occurs when:

*   Moving between Figma, Photoshop, and Illustrator.
*   Switching between different IDEs (e.g., IntelliJ vs VS Code vs Eclipse).
*   Transitioning between terminal shells and web application interfaces.

**Evidence / Observation**

Cross-application usage logs show frequent erroneous shortcut triggers occurring immediately after a user switches active windows from one creative or technical application to another.

**Research Notes**

*   Highlights negative transfer of learning across modern software applications.
*   Foundation for universal shortcut mapping standards and customizable input profiles.
