When performing complex tasks, users must constantly decide whether to search for a keyboard shortcut or reach for the mouse. This decision hesitation ("meta-cognition overhead") often takes longer than performing the action itself via either method.

**Human Impact**

*   Micro-delays during task execution caused by decision paralysis.
*   Reduced productivity from repeatedly picking sub-optimal input pathways.
*   Increased fatigue due to cognitive friction surrounding task strategy.

**Context**

Commonly occurs when:

*   Formatting complex documents in rich text editors.
*   Selecting specific cells or ranges in spreadsheets.
*   Navigating deep multi-tier menu structures in enterprise software.

**Evidence / Observation**

Gaze-tracking and latency logs show pauses up to 1.5 seconds when users decide between mouse hunting and hotkey recall.

**Research Notes**

*   Examines choice architecture in multimodal user interfaces.
*   Recommends contextual input prompts to eliminate decision friction.
