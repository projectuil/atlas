When users mistakenly strike a key combination (e.g., pressing Ctrl+Shift+U, Alt+Shift, or rotating the display via system hotkeys), the application or operating system undergoes a sudden state change—such as changing input language, enabling full screen, toggling overtype mode, or hiding menus. Because the user does not know what key combination was hit, reversing the action is extremely difficult.

**Human Impact**

*   Sudden panic or helplessness as the interface unexpectedly alters state.
*   Disruption of ongoing work to research how to undo the accidental state.
*   Forced computer reboots or application restarts to restore default view states.

**Context**

Commonly occurs when:

*   Resting hands near modifier keys or performing fast chord combinations.
*   Cleaning physical keyboards while power is on.
*   Working in complex professional software with dense shortcut mappings.

**Evidence / Observation**

User forums and support desks frequently process help requests regarding unexplained screen orientation shifts, vanished menu bars, or altered keyboard layout mappings caused by stray keystrokes.

**Research Notes**

*   Examines systemic consequences of non-discoverable, non-modal hotkeys.
*   Highlights the need for state transition notifications and easy undo mechanisms for interface state changes.
