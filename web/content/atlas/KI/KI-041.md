Multilingual users frequently switch between Input Method Editors (IMEs) or language layouts (e.g., English and CJK or Cyrillic). Forgetting the active language state results in typing long streams of gibberish before noticing the mismatch.

**Human Impact**

*   Severe rhythm disruption and need to erase incorrectly typed phrases.
*   Cognitive burden of constantly monitoring the active language indicator icon.
*   Confusion when system shortcuts change depending on active IME layout.

**Context**

Commonly occurs when:

*   Alternating between English code and native-language documentation.
*   Communicating in multilingual chat rooms.

**Evidence / Observation**

Multilingual user logs show frequent "type-delete-switch-retype" cycles, where users enter 5–10 characters, realize the wrong layout is active, backspace completely, and toggle IME.

**Research Notes**

*   Informs research into cursor-adjacent language indicators and automatic auto-correct translation overlays.
