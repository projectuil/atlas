During extended typing sessions, users' hands physically drift away from the home row due to reaching for arrow keys, function rows, numpads, or modifier chords. Re-centering hands requires cognitive effort and tactile search for homing bumps (F and J).

**Human Impact**

*   Disrupted typing rhythm and lowered overall throughput.
*   Physical wrist strain caused by awkward stretching movements.
*   Unintended keystrokes pressed while searching for standard home position.

**Context**

Commonly occurs when:

*   Mixing heavy prose entry with directional arrow key navigation.
*   Using non-ortholinear or compact keyboards without dedicated navigation blocks.

**Evidence / Observation**

High-speed camera recordings reveal frequent hand resets and visual glances down at the keyboard after executing arrow-key navigation or using distant function keys.

**Research Notes**

*   Demonstrates value of home-row navigation layers (e.g., Vim keys, Fn+IJKL).
*   Important for ergonomic keyboard geometry design.
