The two dominant mobile operating systems utilize fundamentally different paradigms for core interactions (e.g., universal "back" gestures vs in-app back buttons, file handling, notification management). Users who must switch between ecosystems face severe muscle-memory disruption.

**Human Impact**

*   Daily operational friction for individuals using one ecosystem for work and another for personal use.
*   Accidental app closures or navigations due to conflicting gesture defaults.
*   Complete lock-in to a single ecosystem out of fear of relearning basic workflows.

**Context**

Commonly occurs when:

*   An employee is issued a corporate Android phone but uses a personal iPhone.
*   Developing or QA testing software across both primary mobile environments.

**Evidence / Observation**

An iOS user handed an Android device will repeatedly swipe from the left edge of the screen to go back inside an app, accidentally closing the app entirely or triggering an unexpected global OS action.

**Research Notes**

Highlights the cognitive switching costs associated with entrenched, proprietary OS interaction models.
