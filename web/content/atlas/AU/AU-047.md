Over-notification of routine security events (e.g., "New sign-in from Chrome on macOS" sent every time cookies clear) desensitizes users, making them ignore security emails during genuine breach events.

**Human Impact**

*   Alert fatigue causing users to ignore critical breach warnings.
*   Anxiety and panic over routine, benign login alerts.
*   Dismissal of legitimate security recommendations.

**Context**

Commonly occurs via:

*   Automated security warning emails sent on routine logins.
*   Push notifications for routine IP address shifts.
*   Enterprise security digest alerts.

**Evidence / Observation**

Users routinely archive or mark "New Sign-in Alert" emails as spam because the system triggers them constantly during normal daily browser use.

**Research Notes**

*   Contributes to PAT-002 — Authentication Fatigue.
*   Demonstrates the danger of alert fatigue generated by low-threshold security notification triggers.
