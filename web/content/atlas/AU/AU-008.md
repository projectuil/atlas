Authentication screens often blend "Sign In," "Sign Up," and "Forgot Password" entry points using ambiguous labeling, low visual distinction, or unified input fields that obscure the system state.

**Human Impact**

*   Attempting to log into non-existent accounts or signing up with existing credentials.
*   Unnecessary error messages and user confusion.
*   Wasted time trying to figure out if an account exists.

**Context**

Commonly occurs on:

*   Mobile screens with limited screen real estate.
*   Landing pages featuring single-field input flows ("Enter your email to continue").
*   Non-standardized custom UI layouts.

**Evidence / Observation**

Users frequently type existing login details into "Sign Up" fields (or vice versa), receiving confusing validation errors like "Email already exists" without an easy route back to "Sign In."

**Research Notes**

*   Contributes to PAT-002 — Authentication Fatigue.
*   Highlights the breakdown of clear visual mapping and core UX patterns in entry screens.
