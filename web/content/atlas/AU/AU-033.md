When offered multiple sign-in technologies (SMS OTP, Authenticator apps, Hardware Keys, Passkeys, Social SSO), users lack the technical context to evaluate which method offers the appropriate balance of security and reliability.

**Human Impact**

*   Choosing less secure defaults (e.g., SMS OTP) despite vulnerability to SIM-swapping.
*   Confusion when faced with unfamiliar terminology like "Passkeys" or "FIDO2".
*   Misguided sense of security while utilizing weak options.

**Context**

Commonly occurs when:

*   Configuring security options in profile settings.
*   Prompted to upgrade from basic passwords to 2FA.
*   Onboarding to sensitive financial or healthcare services.

**Evidence / Observation**

Faced with choosing an MFA option, the majority of non-technical users default to SMS text messages simply due to familiarity, ignoring stronger options like authenticator apps or passkeys.

**Research Notes**

*   Contributes to PAT-002 — Authentication Fatigue.
*   Emphasizes the need for plain-language security guidance rather than technical feature lists.
