MFA push prompts and authentication verification popups lack granular context (such as originating IP location, app icon, browser type, or active task context), making it hard to judge authenticity.

**Human Impact**

*   Hesitation before approving legitimate authentication requests.
*   Defaulting to unsafe habits due to inability to verify origin.
*   General distrust of system security notifications.

**Context**

Commonly occurs when:

*   Receiving push notifications from enterprise MFA apps (Okta, Duo, Authenticator).
*   Interacting with third-party app authorization screens (OAuth consent screens).
*   Approving cross-device login prompts.

**Evidence / Observation**

Users regularly receive an MFA push prompt while logging in, but delay approval because the notification lists an unfamiliar server location (e.g., AWS regional data center IP) instead of their actual physical city.

**Research Notes**

*   Contributes to PAT-002 — Authentication Fatigue.
*   Emphasizes the crucial need for contextual matching (e.g., number-matching prompts) in modern MFA.
