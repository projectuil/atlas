As security controls grow more strict, users find recommended security habits (e.g., unique passwords for every site, strict physical hardware keys) actively conflict with fast, fluid, daily digital access needs.

**Human Impact**

*   Daily friction choosing between speed and safety.
*   Inevitable compromises where security is downgraded to maintain efficiency.
*   Persistent cognitive friction regarding personal security posture.

**Context**

Commonly occurs during:

*   High-frequency daily tasks (checking email, internal communication tools).
*   Quick transactions on mobile devices while on the go.
*   Sharing temporary account access with family or team members.

**Evidence / Observation**

Users intentionally disable available security controls (e.g., turning off 2FA, setting minimal PINs) whenever platform policy permits, explicitly trading away safety for convenience.

**Research Notes**

*   Contributes to PAT-002 — Authentication Fatigue.
*   Captures the foundational compromise users make when security design imposes prohibitive operational friction.
