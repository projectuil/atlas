As work progresses, files transition from active use to historical reference. Users frequently struggle to determine the appropriate point at which a file should be archived instead of remaining within active project areas. This uncertainty leads to active workspaces becoming increasingly cluttered with completed or inactive files.

**Human Impact**

*   Cluttered project workspaces.
*   Reduced navigation efficiency.
*   Increased cognitive load.
*   Slower information retrieval.
*   Reduced project organization.

**Context**

Commonly occurs in:

*   Long-term software projects.
*   Research repositories.
*   Business documentation.
*   Academic projects.
*   Personal knowledge collections.

**Evidence / Observation**

This behaviour is consistently observed as projects mature. Users often recognize that certain files are no longer actively used but remain uncertain whether they should archive them or continue treating them as active resources. Traditional file systems distinguish storage locations but provide limited guidance regarding lifecycle transitions.

**Research Notes**

*   Contributes to **PAT-005 — Complexity Growth.**
*   Highlights lifecycle transition rather than deletion.
*   Related to long-term information management and workspace organization.
