Users often remember a file but gradually lose the context surrounding it. After days, weeks, or months, they may no longer remember why the file was created, what task it belongs to, whether it is complete, or what should be done next. As a result, users spend additional time reconstructing the context before they can continue their work.

**Human Impact**

*   Time lost rebuilding context.
*   Interrupted workflow.
*   Increased cognitive load.
*   Reduced productivity.
*   Greater hesitation when resuming previous work.

**Context**

**Commonly occurs in:**

*   Long-term projects.
*   Research documentation.
*   Software development.
*   Academic work.
*   Personal document collections.

**Evidence / Observation**

This behaviour is frequently observed when users revisit previously created files after a period of inactivity. Although the file is successfully located, users often need to reopen related documents, revisit folders, read previous notes, or inspect the file contents before remembering its original purpose.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Context is often more difficult to remember than the file itself.
*   Closely related to long-term knowledge management and workflow continuity.
