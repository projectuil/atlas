Many files are created or modified based on information contained in other files. Over time, users remember the individual documents but lose the understanding of how they influenced one another. As a result, users must manually inspect multiple files to reconstruct their dependencies before continuing their work.

**Human Impact**

*   Increased time reconstructing project history.
*   Higher cognitive load.
*   Interrupted workflow.
*   Duplicate analysis.
*   Reduced understanding of project evolution.

**Context**

Commonly occurs in:

*   Software development.
*   Research documentation.
*   Business reporting.
*   Academic writing.
*   Collaborative projects.

**Evidence / Observation**

This behaviour is consistently observed in projects where multiple documents evolve together. Users frequently know that one document was created using information from another but can no longer identify the dependency between them. Existing file systems organize files independently and provide limited support for preserving logical dependencies between related documents.

**Research Notes**

*   Contributes to **PAT-003 — Relationship Blindness.**
*   Focuses on dependency relationships rather than simple file associations.
*   Related to project evolution, knowledge organization, and information traceability.
