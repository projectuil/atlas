Users frequently leave work incomplete across multiple files but later forget which files still require attention. Since unfinished work is not explicitly represented within traditional file systems, users rely on memory to identify pending tasks, resulting in overlooked documents and interrupted workflow.

**Human Impact**

*   Unfinished work is forgotten.
*   Time lost reviewing files.
*   Interrupted workflow.
*   Increased cognitive load.
*   Reduced productivity.

**Context**

Commonly occurs in:

*   Research projects.
*   Software development.
*   Academic assignments.
*   Business documentation.
*   Creative work.

**Evidence / Observation**

This behaviour is repeatedly observed when users pause work and return after several days. Although the files remain available, users often cannot remember which documents were partially completed and which were already finished, leading to unnecessary review and delayed task completion.

**Research Notes**

*   Contributes to **PAT-001 — Context Loss Over Time**.
*   Highlights the disconnect between file storage and task progress.
*   Closely related to workflow continuity and project management.
