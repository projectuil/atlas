Users often store files across multiple storage locations, such as local drives, cloud storage services, external devices, and shared folders. Over time, they struggle to remember where a particular file is stored, making retrieval slower and more dependent on trial and error.

**Human Impact**

*   Time lost checking multiple storage locations.
*   Interrupted workflow.
*   Increased cognitive load.
*   Duplicate downloads or file creation.
*   Reduced productivity.

**Context**

Commonly occurs when using:

*   Local storage.
*   Cloud storage platforms.
*   External hard drives.
*   USB storage devices.
*   Shared organizational storage.

**Evidence / Observation**

This behaviour is consistently observed as users adopt multiple storage services for personal and professional work. Instead of remembering a file's content or purpose, users must first remember its storage location, often leading to repeated searches across different devices and services.

*   Contributes to **PAT-001 — Context Loss Over Time**.
*   Highlights fragmentation across modern storage environments.
