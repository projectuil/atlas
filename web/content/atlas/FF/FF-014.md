Users often cannot determine the current status of a file by looking at it. They may not know whether it is incomplete, under review, finalized, outdated, or no longer relevant. As a result, users frequently need to open the file or rely on memory to understand its current state.

**Human Impact**

*   Time lost checking file progress.
*   Increased uncertainty.
*   Interrupted workflow.
*   Risk of using outdated information.
*   Reduced confidence in project organization.

**Context**

**Commonly occurs in:**

*   Long-term projects.
*   Team collaboration.
*   Research documentation.
*   Business reports.
*   Academic assignments.

**Evidence / Observation**

This behaviour is consistently observed when multiple versions or drafts of a file exist. Users often reopen documents simply to determine whether additional work is required or whether the file represents the latest completed version, as traditional file systems provide little indication of a file's workflow status.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Distinguishes file existence from workflow progress.
*   Related to project management, version awareness, and task continuity.
