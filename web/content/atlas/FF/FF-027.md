Many tasks require users to work with multiple related files in a particular sequence. Over time, users remember the files themselves but forget the order in which they should be opened or reviewed. Without remembering the original workflow, users spend additional time reconstructing the correct sequence before meaningful work can continue.

**Human Impact**

*   Delayed task resumption.
*   Time lost reopening files in different orders.
*   Increased cognitive load.
*   Interrupted workflow.
*   Reduced productivity.

**Context**

Commonly occurs in:

*   Software development projects.
*   Research documentation.
*   Academic assignments.
*   Business documentation.
*   Creative production workflows.

**Evidence / Observation**

This behaviour is frequently observed when users return to ongoing work after a period of inactivity. Although all required files remain available, users often cannot remember which document should be opened first, which files provide supporting information, or how the workflow previously progressed. Existing file systems organize files independently but provide little support for preserving the user's working sequence.

**Research Notes**

*   Contributes to **PAT-002 — Memory Dependency.**
*   Focuses on workflow sequence rather than file relationships.
*   Related to workflow continuity and task resumption.
