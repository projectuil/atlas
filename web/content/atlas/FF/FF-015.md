Users often move files to improve organization but later struggle to remember their new location. Although the reorganization may initially make sense, users gradually forget where files were relocated, making future retrieval more difficult.

**Human Impact**

*   Time lost searching relocated files.
*   Interrupted workflow.
*   Increased cognitive load.
*   Reduced confidence in file organization.
*   Duplicate searching across multiple folders.

**Context**

**Commonly occurs when:**

*   Cleaning up folders.
*   Reorganizing projects.
*   Moving files between storage devices.
*   Migrating files to cloud storage.
*   Archiving completed work.

**Evidence / Observation**

This behaviour is frequently observed after users reorganize their files or folders. Initially, the new structure is familiar, but over time users forget where specific files were moved and often search their previous locations before locating the new one.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Organization changes improve structure but increase memory dependence.
*   Related to file navigation and long-term information retrieval.
