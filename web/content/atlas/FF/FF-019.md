Users often do not fully trust the results returned by file search systems. Even after performing a search, they continue browsing folders manually because they are uncertain whether the search has found every relevant file or whether important files have been missed.

**Human Impact**

*   Time lost verifying search results.
*   Increased cognitive effort.
*   Repeated manual navigation.
*   Reduced confidence in file discovery.
*   Slower information retrieval.

**Context**

Commonly occurs when searching for:

*   Project documents.
*   Research materials.
*   Older files.
*   Files stored across multiple folders.
*   Documents with similar names.

**Evidence / Observation**

This behaviour is frequently observed across desktop operating systems and cloud storage platforms. Users often perform multiple searches using different keywords or manually browse folders after searching because they lack confidence that the search results are complete.

**Research Notes**

*   Contributes to **PAT-001 — Context Loss Over Time**.
*   Highlights the difference between finding results and trusting results.
*   Related to information retrieval and search confidence.
