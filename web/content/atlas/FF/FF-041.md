Projects often contain multiple files covering the same topic, including drafts, summaries, notes, presentations, and reports. Users frequently struggle to determine which file should be treated as the authoritative source of information, resulting in uncertainty and inconsistent use of project knowledge.

**Human Impact**

*   Time lost comparing files.
*   Increased uncertainty.
*   Duplicate edits.
*   Inconsistent information usage.
*   Reduced confidence.

**Context**

Commonly occurs in:

*   Research documentation.
*   Business documentation.
*   Software documentation.
*   Academic work.
*   Collaborative projects.

**Evidence / Observation**

This behaviour is frequently observed in projects where knowledge is distributed across multiple documents. Users often recognize that several files discuss the same subject but cannot determine which document should be considered the primary reference. Existing file systems treat all files equally and provide limited support for identifying authoritative information sources.

*   Contributes to **PAT-004 — Storage Without Understanding.**
*   Focuses on information authority rather than version history.
