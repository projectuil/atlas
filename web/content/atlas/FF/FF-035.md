Users frequently create multiple files as part of the same activity, task, or project session. Over time, they remember individual files but forget which documents, images, spreadsheets, presentations, or supporting resources were originally created together. This makes it difficult to reconstruct complete work sessions and retrieve all relevant materials.

**Human Impact**

*   Time lost searching for related files.
*   Interrupted workflow.
*   Increased cognitive load.
*   Incomplete project understanding.
*   Reduced productivity.

**Context**

Commonly occurs in:

*   Research projects.
*   Software development.
*   Business documentation.
*   Academic assignments.
*   Creative production.

**Evidence / Observation**

This behaviour is consistently observed when users revisit older work. Although they successfully locate one file, they often cannot remember the additional resources that were created during the same working session. Existing file systems preserve creation timestamps but provide limited support for identifying files that originated together as part of a single activity.

**Research Notes**

*   Contributes to **PAT-003 — Relationship Blindness.**
*   Focuses on temporal relationships between files.
*   Related to project organization and workflow reconstruction.
