As digital file collections grow over time, users gradually lose their overall understanding of their own files. Although individual files remain accessible, users increasingly struggle to remember what information they possess, how files are organized, how resources relate to one another, and where important knowledge can be found. Managing files becomes progressively more dependent on memory rather than understanding.

**Human Impact**

*   Reduced confidence in personal file management.
*   Increased time spent searching for information.
*   Higher cognitive load.
*   Duplicate work and forgotten resources.
*   Declining productivity as file collections expand.

**Context**

Commonly occurs in:

*   Long-term personal file collections.
*   Academic and research repositories.
*   Software development projects.
*   Business documentation.
*   Cloud storage accumulated over several years.

**Evidence / Observation**

This behaviour is consistently observed as users accumulate hundreds or thousands of digital files over extended periods. While individual Human Frictions such as locating files, remembering filenames, understanding file purpose, or tracking project status occur independently, they collectively contribute to a broader loss of understanding of the user's entire file collection.
