Users often manage collections of active files but cannot easily determine which files require immediate attention. Although all files remain accessible, traditional file systems provide limited support for distinguishing urgent work from lower-priority documents. Users therefore rely on memory to decide what should be worked on next.

**Human Impact**

*   Delayed decision-making.
*   Interrupted workflow.
*   Increased cognitive load.
*   Important work is overlooked.
*   Reduced productivity.

**Context**

Commonly occurs in:

*   Long-term projects.
*   Academic coursework.
*   Software development.
*   Business documentation.
*   Personal task management.

**Evidence / Observation**

This behaviour is consistently observed when users maintain multiple active documents simultaneously. After returning to work, users often recognize several unfinished files but cannot immediately determine which one should receive attention first. Existing file systems primarily organize files by names, folders, and timestamps rather than by the urgency of the user's work.

**Research Notes**

*   Contributes to **PAT-002 — Memory Dependency.**
*   Focuses on prioritization rather than workflow status.
*   Related to task continuity, decision-making, and productivity.
