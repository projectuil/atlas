Users often remember the task, project, or purpose for which a file was created but cannot easily locate the file itself. Traditional file systems organize files by names and locations rather than by the user's original intent, making task-based retrieval difficult.

**Human Impact**

*   Time spent searching for task-related files.
*   Interrupted workflows.
*   Increased cognitive effort.
*   Duplicate file creation.
*   Reduced productivity.

**Context**

**Commonly occurs when searching for files related to:**

*   College assignments.
*   Office work.
*   Client projects.
*   Personal tasks.
*   Research activities.

**Evidence / Observation**

Users frequently search using phrases such as "the file I made for yesterday's meeting" or "my college assignment document" instead of remembering the filename or folder. Existing file systems provide limited support for retrieving files based on the purpose for which they were created.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Highlights the difference between human task-oriented memory and system-based file organization.
*   Closely related to semantic and intent-based file retrieval.
