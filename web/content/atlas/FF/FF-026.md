Users often remember successfully locating a file in the past but later cannot remember how they found it. Although the file still exists, users forget the navigation path, search method, folder sequence, or retrieval process that previously led them to the correct file. As a result, they must repeat the search from the beginning instead of following the same retrieval path.

**Human Impact**

*   Time lost repeating previous searches.
*   Interrupted workflow.
*   Increased cognitive load.
*   Frustration during file retrieval.
*   Reduced confidence in remembering previous work.

**Context**

Commonly occurs when:

*   Revisiting older projects.
*   Returning to work after several days or weeks.
*   Accessing deeply nested folders.
*   Switching between multiple storage locations.
*   Resuming infrequently performed tasks.

**Evidence / Observation**

This behaviour is frequently observed when users have successfully located a file before but cannot reproduce the same retrieval process later. Users often remember statements such as _"I found this yesterday"_ or _"I know I opened it before,"_ yet they cannot remember whether they used folder navigation, file search, recent files, bookmarks, or another method to reach it. Existing file systems preserve files but generally do not preserve the user's retrieval history in a way that supports repeating previous discovery paths.

**Research Notes**

*   Contributes to **PAT-002 — Memory Dependency.**
*   Highlights the difference between remembering a file and remembering how it was retrieved.
*   Related to retrieval behaviour, workflow continuity, and long-term information access.
