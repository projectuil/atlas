Users frequently create files that begin as independent documents but gradually become part of a larger body of work. Over time, users struggle to determine whether these files should continue to exist independently or be integrated into a broader project structure. This uncertainty contributes to fragmented information and inconsistent project organization.

**Human Impact**

*   Fragmented project structure.
*   Duplicate information.
*   Increased navigation effort.
*   Higher cognitive load.
*   Reduced long-term maintainability.

**Context**

Commonly occurs in:

*   Research documentation.
*   Software development.
*   Academic work.
*   Business documentation.
*   Personal knowledge management.

**Evidence / Observation**

This behaviour is consistently observed as projects expand over time. Users often create standalone notes, documents, or reference materials that later become relevant to larger initiatives. Existing file systems provide limited support for evolving isolated files into organized project structures while preserving their context.

**Research Notes**

*   Contributes to **PAT-005 — Complexity Growth.**
*   Highlights structural evolution rather than file organization.
*   Related to long-term project architecture and information management.
