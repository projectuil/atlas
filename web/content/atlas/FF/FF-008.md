Users often forget the location where they saved a newly created file. Although the file exists, recalling its storage location later becomes difficult, particularly when multiple folders or storage locations are available.

**Human Impact**

*   Time lost locating saved files.
*   Interrupted workflows.
*   Increased cognitive load.
*   Frustration during file retrieval.
*   Reduced confidence in file organization.

**Context**

**Commonly occurs after creating:**

*   Documents.
*   Presentations.
*   Spreadsheets.
*   Design files.
*   Project resources.

The problem becomes more common when users save files across local storage, external drives, or cloud services.

**Evidence / Observation**

This behaviour is repeatedly observed across desktop operating systems and productivity applications. Users frequently save files quickly to continue working but later struggle to remember the chosen location, especially when similar folder structures exist or multiple storage services are used.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Closely related to file discovery and navigation.
*   Becomes more frequent as the number of storage locations increases.
