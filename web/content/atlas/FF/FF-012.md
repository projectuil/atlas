Modern projects often consist of many related files, including documents, spreadsheets, presentations, images, source code, and notes. Although these files contribute to the same project, traditional file systems present them as independent items, making it difficult for users to understand how they relate to one another.

**Human Impact**

*   Increased navigation time.
*   Difficulty understanding project structure.
*   Higher cognitive load.
*   Duplicate work.
*   Reduced project comprehension.

**Context**

**Commonly occurs in:**

*   Software development projects.
*   Research repositories.
*   Business documentation.
*   Academic projects.
*   Collaborative team workspaces.

**Evidence / Observation**

This behaviour is consistently observed in projects containing multiple supporting files. Users frequently remember that several files are connected but must manually search and infer those relationships because existing file systems primarily organize information through folders and filenames rather than logical project relationships.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Highlights the difference between logical project relationships and physical file organization.
*   Related to project navigation, knowledge organization, and information discovery.
