Many files rely on external resources such as linked images, datasets, libraries, templates, fonts, configuration files, or referenced documents. Users often cannot determine whether a file is completely self-contained or whether additional resources are required for it to function correctly.

**Human Impact**

*   Missing project resources.
*   Interrupted workflow.
*   Increased troubleshooting time.
*   Project portability issues.
*   Reduced confidence when sharing or archiving files.

**Context**

Commonly occurs in:

*   Software development.
*   Graphic design.
*   Video production.
*   Research projects.
*   Business documentation.

**Evidence / Observation**

This behaviour is frequently observed when users move, archive, share, or revisit projects. A file may appear complete but later fail because required external resources were forgotten or separated from the primary document. Traditional file systems primarily manage individual files rather than representing their dependency on external resources.

**Research Notes**

*   Contributes to **PAT-003 — Relationship Blindness.**
*   Highlights hidden resource dependencies.
*   Related to project portability and resource management.
