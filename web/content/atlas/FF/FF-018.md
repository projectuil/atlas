Users often hesitate to delete files because they are uncertain whether the files are still needed. Even when files appear outdated or unused, users fear losing important information, resulting in unnecessary file accumulation and increasingly cluttered storage.

**Human Impact**

*   Accumulation of unnecessary files.
*   Increased storage clutter.
*   Reduced confidence during file management.
*   Slower navigation.
*   Increased cognitive load.

**Context**

Commonly occurs during:

*   Storage cleanup.
*   Project completion.
*   Device migration.
*   Folder reorganization.
*   Archive management.

**Evidence / Observation**

This behaviour is commonly observed when users organize personal or professional files. Rather than deleting uncertain files, users often keep them "just in case," causing folders to grow over time and making future navigation more difficult.

**Research Notes**

*   Contributes to **PAT-001 — Context Loss Over Time**.
*   Highlights uncertainty in file lifecycle management.
*   Related to file organization, storage management, and long-term information retention.
