As projects grow, the number of files and folders increases, making it harder for users to understand the overall project structure. Even when information is organized correctly, navigating large collections becomes more difficult and locating the right file requires greater effort.

**Human Impact**

*   More time spent navigating folders.
*   Increased cognitive load.
*   Difficulty understanding project structure.
*   Important files are overlooked.
*   Reduced productivity.

**Context**

Commonly occurs in:

*   Software development projects.
*   Academic and research work.
*   Business documentation.
*   Creative projects.
*   Shared team workspaces.

**Evidence / Observation**

This behaviour is consistently observed as projects expand over time. Users initially understand a project's organization but gradually lose track as additional files and folders are created. The problem occurs across desktop operating systems, cloud storage platforms, and collaborative work environments regardless of the folder structure used.

**Research Notes**

*   Contributes to **PAT-001 — Context Loss Over Time**.
*   Complexity increases as projects evolve.
*   Closely related to file navigation and information retrieval.
