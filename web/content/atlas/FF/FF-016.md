Users often remember creating or editing a file but cannot remember which application was used. When multiple applications support similar file types, users spend additional time determining the correct application before continuing their work.

**Human Impact**

*   Delayed task resumption.
*   Interrupted workflow.
*   Increased cognitive effort.
*   Time lost opening files with different applications.
*   Reduced productivity.

**Context**

Commonly occurs with:

*   Design files.
*   Office documents.
*   Programming projects.
*   Multimedia files.
*   Specialized professional software.

**Evidence / Observation**

This behaviour is commonly observed when users revisit files created weeks or months earlier. They often remember the work itself but forget which software was originally used, particularly when multiple compatible applications are installed or when files are exchanged between different devices.

**Research Notes**

*   Contributes to **PAT-001 — Context Loss Over Time**.
*   Highlights the relationship between files and their working environment.
*   Related to workflow continuity and application discovery.
