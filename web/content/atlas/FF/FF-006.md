Users often remember what a file contains but cannot remember its filename or storage location. Since most file systems rely heavily on filenames and folder structures, locating the correct file becomes difficult despite the user remembering its purpose or content.

**Human Impact**

*   Longer search times.
*   Increased cognitive effort.
*   Interrupted workflows.
*   Frustration during information retrieval.
*   Reduced productivity.

**Context**

**Commonly occurs when searching for:**

*   Notes and documents.
*   Presentations.
*   Reports.
*   Academic materials.
*   Previously created project files.

**Evidence / Observation**

This behaviour is commonly observed in personal and professional environments. Users frequently describe a document by its contents or purpose instead of its filename, yet existing file management systems primarily require filenames, locations, or keywords to retrieve it efficiently.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Highlights the gap between human memory and traditional file organization.
*   Closely related to semantic search and contextual information retrieval.
