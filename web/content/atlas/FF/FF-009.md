Users often organize similar projects using different folder structures and naming conventions. As a result, finding information becomes less predictable, and moving between projects requires additional effort to understand each unique organization.

**Human Impact**

*   Slower navigation between projects.
*   Increased cognitive load.
*   Difficulty locating related resources.
*   Reduced organizational consistency.
*   Lower long-term productivity.

**Context**

**Commonly occurs in:**

*   Academic projects.
*   Software development.
*   Business documentation.
*   Personal file collections.
*   Freelance and client work.

**Evidence / Observation**

This behaviour is frequently observed when users create new projects over time without following a consistent organizational approach. Similar projects may contain entirely different folder hierarchies, making navigation dependent on memory rather than predictable structure.

**Research Notes**

*   Contributes to PAT-001 — Context Loss Over Time.
*   Organization habits often evolve without standardization.
*   Related to long-term information management.
