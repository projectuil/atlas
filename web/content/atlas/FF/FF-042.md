Over time, projects accumulate new files that appear similar to existing ones. Users frequently cannot determine why a new file was created instead of updating an earlier document. Without understanding the reasoning behind this decision, users struggle to interpret project history and maintain consistency.

**Human Impact**

*   Confusion during project maintenance.
*   Increased cognitive load.
*   Duplicate work.
*   Slower project understanding.
*   Reduced documentation quality.

**Context**

Commonly occurs in:

*   Long-term projects.
*   Research documentation.
*   Software repositories.
*   Business records.
*   Academic work.

**Evidence / Observation**

This behaviour is consistently observed in evolving projects where new files are introduced instead of modifying existing ones. When revisiting the project, users often question whether the new document represents a replacement, a specialized extension, or an accidental duplication. Traditional file systems preserve files but rarely preserve the reasoning behind their creation.

*   Contributes to **PAT-001 — Context Loss Over Time.**
*   Focuses on decision context rather than file duplication.
