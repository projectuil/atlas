Although websites often provide similar services, each platform organizes its interface differently. Navigation menus, search bars, account settings, profile pages, and important actions are placed in different locations and follow different interaction patterns. As a result, users must repeatedly learn how each website works instead of applying knowledge gained from previous websites. This repeated learning increases cognitive effort and slows task completion.

**Human Impact**

*   Increased learning time for new websites.
*   Reduced efficiency when switching between platforms.
*   Greater cognitive load caused by inconsistent interfaces.
*   Increased dependence on tutorials or trial-and-error exploration.
*   Reduced confidence when using unfamiliar websites.

**Context**

**Commonly occurs when:**

*   Using a new website for the first time.
*   Switching between competing online services.
*   Performing similar tasks on different platforms.
*   Learning unfamiliar web applications.
*   Accessing redesigned websites.

**Evidence / Observation**

This behaviour is consistently observed across the modern web. Users frequently know what they want to accomplish but spend additional time locating menus, settings, or features because each website adopts its own navigation structure. Similar actions such as changing account settings, downloading files, searching information, or managing notifications often require different navigation paths across platforms. Even experienced users must temporarily relearn interface layouts whenever they begin using a new website or when existing websites introduce major interface redesigns.

**Research Notes**

*   Focuses on interface consistency across websites.
*   Differs from WI-001 by emphasizing interaction rather than website selection.
*   Demonstrates how inconsistent interface design increases cognitive effort.
*   Likely contributes to future behavioural patterns related to Interface Familiarity, Navigation Learning, and Cognitive Adaptation.
