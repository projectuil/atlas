The boundaries separating host operating systems, browser frames, browser extensions, remote websites, and client-side single-page applications have blurred entirely. Users struggle to construct an accurate mental model of where one software layer ends and another begins, resulting in misplaced trust and operational confusion.

**Human Impact**

*   Granting excessive security permissions to malicious browser extensions.
*   Inability to troubleshoot UI glitches injected by third-party browser add-ons.
*   Confusion over whether data is stored locally on the PC or remotely in the cloud.
*   Misunderstanding the difference between native desktop apps and wrapped web apps.

**Context**

Commonly occurs when:

*   Installing browser extensions that inject UI elements (e.g., coupon finders, password managers) directly into web pages.
*   Interacting with Progressive Web Apps (PWAs) that run outside traditional browser chrome.
*   Encountering phishing overlays or extension-injected pop-ups on legitimate websites.

**Evidence / Observation**

When users install shopping or discount extensions, those extensions frequently inject banners directly into external e-commerce web pages. In testing, users believe those banners were built by the e-commerce store itself, completely unaware that local browser software modified the page DOM in real time.

**Research Notes**

*   Documents total breakdown in user mental models regarding software boundaries.
*   Analyzes security vulnerabilities introduced by DOM-manipulating browser add-ons.
*   Informs Architectural Blur and Extension Misattribution patterns.
