**Pattern**

Users expect digital activities to continue seamlessly across time and devices, but interruptions in sessions frequently disrupt task continuity. Automated logouts, silent token expirations, unannounced cookie wipes, and non-synchronizing cross-device states repeatedly sever user workflows mid-task.

This pattern highlights the gap between security-driven session expiration policies and human operational continuity. When a user returns to a tab or transitions from mobile to desktop, they are frequently greeted by unexpected login screens or lost input fields, forcing them to pause, re-authenticate, and rebuild state.

**Human Impact**

*   Frustration caused by abrupt, unexplained logouts during active task execution.
*   Loss of unsaved text, form entries, or configuration states.
*   Hesitation to step away from active web tools for fear of session timeouts.
*   Time wasted performing manual hacks (e.g., emailing links) to move sessions across devices.
*   Disruption of focus and task momentum due to unexpected authentication gates.

**Evidence**

This Pattern is currently supported by the following Human Frictions:

*   **WI-028** – Users struggle to determine whether they are currently signed in to a website.
*   **WI-029** – Users struggle to understand why websites automatically sign them out.
*   **WI-043** – Users struggle to continue interrupted web tasks across different devices.

Across these observations, session terminations operate as invisible system disruptions that break user focus and ruin operational momentum.

**Research Notes**

Captures the friction between defensive security timeouts and continuous user experience. Emphasizes the need for state-preserving session management and intuitive cross-device task handoffs.
