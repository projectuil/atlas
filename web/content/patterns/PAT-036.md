**Pattern**

Similar digital tasks require different interaction patterns across websites, preventing users from transferring previously learned knowledge. Web applications lack universal standards for basic features—such as settings placement, user state indicators, dynamic personalization, and layout hierarchies—forcing users to re-learn interaction models continuously.

This pattern demonstrates how UI volatility across platforms breaks established user habits. When websites suddenly alter their design, display personalized variations to different users, or use unconventional control placements, cognitive friction increases, making simple web tasks feel unfamiliar and error-prone.

**Human Impact**

*   Cognitive disorientation when navigating unfamiliar or redesigned websites.
*   Increased error rates caused by applying learned habits to non-standard UI elements.
*   Confusion when identical web pages display different states or layouts across users.
*   Repeated effort required to re-locate settings and navigation options across platforms.
*   Difficulty distinguishing between local browser quirks and remote server changes.

**Evidence**

This Pattern is currently supported by the following Human Frictions:

*   **WI-002** – Users struggle to understand how to navigate an unfamiliar website layout.
*   **WI-005** – Users struggle to understand the purpose of different sections within a website.
*   **WI-006** – Users struggle to remember where features and settings are located on websites they have previously used.
*   **WI-017** – Users struggle when websites unexpectedly change their interface or functionality.
*   **WI-030** – Users struggle to understand why the same website displays different content for different users.
*   **WI-038** – Users struggle to distinguish between browser problems and website problems.

Across these observations, interface divergence forces users to continuously abandon past operational knowledge in favor of trial-and-error adaptation.

**Research Notes**

Demonstrates that arbitrary visual innovation over convention impairs user efficiency. Systemic research is needed to define foundational web design conventions that maintain domain personality while standardizing core tasks.
