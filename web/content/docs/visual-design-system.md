__PROJECT UIL VISUAL DESIGN SYSTEM__

__Version 1\.0__

__Purpose:__  
Define every visual element used by Project UIL so that every image, presentation, document, website, and social media post feels like it belongs to the same research initiative\.

__1\. Design Philosophy__

Every visual should communicate:

- Simplicity 
- Clarity 
- Research 
- Trust 
- Human\-centred thinking 

Design should never distract from the research\.

__2\. Design Principles__

__Principle 1 - Minimalism__

Remove anything that doesn't add meaning\.

__Principle 2 - Consistency__

The same colours, typography, spacing, and layouts should be used everywhere\.

__Principle 3 - Readability__

Content is always more important than decoration\.

__Principle 4 - Timelessness__

Avoid design trends that will look outdated quickly\.

__3\. Official Colour Palette__

__Primary__

__Matte Black__

\#0B0B0B

Purpose:

- Backgrounds 
- Covers 
- Headers 

__Secondary__

__White__

\#FFFFFF

Purpose:

- Main text 
- Icons 

__Accent__

__Emerald Green__

\#10B981

Purpose:

- Highlights 
- Observation numbers 
- Important labels 
- Dividers 

Never use the accent for large blocks\.

__Neutral Grey__

\#A1A1AA

Purpose:

- Captions 
- Metadata 
- Dates 

__4\. Typography__

__Primary Font__

__Inter__

Used for:

- Titles 
- Body text 
- Documents 
- Website 

__Secondary Font__

IBM Plex Sans

Only if Inter isn't available\.

__5\. Logo Rules__

The logo must always:

- Be centred or left\-aligned\. 
- Have sufficient whitespace around it\. 
- Use approved colours only\. 
- Remain flat \(no shadows or 3D\)\. 

Never:

- Stretch 
- Rotate 
- Add effects 
- Change colours 

__6\. Spacing System__

Use a consistent spacing scale:

8 px

16 px

24 px

32 px

48 px

64 px

This creates a balanced visual rhythm\.

__7\. Grid System__

Every design should follow a simple grid\.

For example:

Title



Content



Insight



Footer

Avoid random placement of elements\.

__8\. Icon Style__

Icons should be:

- Simple 
- Line\-based 
- Monochrome 
- Minimal 

Avoid colourful or decorative icons\.

__9\. Photography Style__

When using photos:

Choose:

- Real environments 
- Workspaces 
- Everyday interactions 
- Research settings 

Avoid:

- Stock photos with fake smiles 
- Futuristic robots 
- Generic AI imagery 

__10\. Illustration Style__

Illustrations should be:

- Flat 
- Geometric 
- Minimal 

No cartoon characters\.

No fantasy elements\.

__11\. LinkedIn Post Template__

Every post image follows this layout:

PROJECT UIL



Title



Observation



Insight



AO\-001

Research\. Understand\. Build\.

Consistent margins, typography, and colours\.

__12\. Banner Guidelines__

Include:

- Project UIL 
- Tagline 
- Plenty of negative space 
- Subtle geometric patterns 

Avoid overcrowding\.

__13\. Presentation Template__

Slides should contain:

- One main idea 
- Minimal text 
- Consistent typography 
- Black background 
- White text 
- Emerald highlights 

__14\. Document Template__

Research papers should include:

- Project UIL logo 
- Document title 
- Version number 
- Date 
- Footer with page numbers 

__15\. Atlas Graphics__

Every Atlas Observation graphic should include:

- Observation ID 
- Category 
- Human Friction 
- One key insight 
- Project UIL branding 

__16\. Accessibility Standards__

Every visual must:

- Meet good colour contrast\. 
- Use readable font sizes\. 
- Avoid relying on colour alone to communicate meaning\. 
- Remain understandable on both desktop and mobile\. 

__17\. Design Quality Checklist__

Before publishing any visual:

- Does it use approved colours? 
- Does it use approved fonts? 
- Is the layout consistent? 
- Is the message immediately clear? 
- Is there unnecessary decoration? 
- Does it reflect Project UIL's research identity? 

If any answer is "No", revise before publishing\.

__18\. Visual Motto__

__Design should never compete with the research\. It should quietly support it\.__
