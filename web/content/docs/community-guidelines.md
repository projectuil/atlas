__PROJECT UIL COMMUNITY, COLLABORATION & COMMUNICATION GUIDELINES__

__Version 1\.0__

__1\. Purpose__

This document defines how Project UIL communicates with individuals, organisations, researchers, designers, developers, educators, and the broader community\.

Every interaction should reflect the values of Project UIL\.

__2\. Communication Philosophy__

Project UIL exists to:

- Learn 
- Observe 
- Collaborate 
- Share knowledge 
- Encourage thoughtful discussion 

Communication is not used to:

- Win arguments 
- Seek attention 
- Promote ego 
- Create unnecessary controversy 

__3\. Core Communication Principles__

Every interaction should be:

- Respectful 
- Curious 
- Honest 
- Professional 
- Evidence\-based 
- Inclusive 

__4\. Community Values__

The Project UIL community should encourage:

- Open discussion 
- Different perspectives 
- Constructive criticism 
- Shared learning 
- Respect for evidence 

Everyone is welcome to contribute thoughtfully\.

__5\. Comment Guidelines__

__Always__

- Thank people for contributing\. 
- Ask follow\-up questions when appropriate\. 
- Clarify misunderstandings politely\. 
- Acknowledge useful corrections\. 
- Encourage discussion\. 

__Never__

- Insult others\. 
- Mock different opinions\. 
- Escalate conflicts\. 
- Respond emotionally\. 

__6\. Direct Messages__

Messages should be answered professionally\.

Types of messages:

__Research Questions__

Respond with available information\.

If the answer is unknown:

"This is an area we're still researching\."

__Collaboration Requests__

Evaluate:

- Does it align with Project UIL's mission? 
- Does it contribute to understanding human problems? 
- Is the collaboration ethical? 

If not, politely decline\.

__General Questions__

Answer when possible\.

If time does not permit, acknowledge the message and respond later if appropriate\.

__7\. Collaboration Principles__

Project UIL collaborates with people who value:

- Research 
- Human\-centred thinking 
- Accessibility 
- Ethics 
- Long\-term impact 

Collaboration should strengthen the mission rather than distract from it\.

__8\. Professional Conduct__

Always:

- Be punctual\. 
- Keep commitments\. 
- Credit contributions\. 
- Admit mistakes\. 
- Correct inaccuracies\. 

__9\. Handling Feedback__

__Positive Feedback__

Express appreciation\.

Recognise thoughtful engagement\.

__Constructive Criticism__

Listen carefully\.

Evaluate objectively\.

Improve when appropriate\.

__Incorrect Information__

Respond calmly with clarification and supporting evidence where possible\.

__Hostile Behaviour__

Do not engage in arguments\.

If necessary, end the conversation respectfully or use platform moderation tools\.

__10\. Attribution__

Whenever external work influences Project UIL:

- Credit the original source\. 
- Distinguish between original observations and external ideas\. 
- Respect copyright and intellectual property\. 

__11\. Privacy__

Never share:

- Personal data without consent\. 
- Confidential conversations\. 
- Sensitive research information\. 

When discussing real observations, remove identifying details\.

__12\. Public Representation__

Anyone communicating as Project UIL should:

- Stay within the project's mission\. 
- Avoid personal opinions presented as official positions\. 
- Speak clearly and professionally\. 

__13\. Email Standards__

Use a professional structure:

- Clear subject line 
- Greeting 
- Purpose 
- Supporting information 
- Closing 
- Project UIL signature 

Example signature:

Project UIL

Independent Research Initiative

Understanding Human Problems Before Building Technology\.

research\.projectuil@gmail\.com

__14\. LinkedIn Standards__

Every interaction should:

- Add value\. 
- Stay relevant\. 
- Encourage thoughtful discussion\. 

Avoid generic comments such as:

- "Great post\!" 
- "Amazing\!" 

Instead, contribute a specific observation or question\.

__15\. Conflict Resolution__

If disagreements arise:

1. Understand the concern\. 
2. Clarify facts\. 
3. Acknowledge valid points\. 
4. Explain your reasoning\. 
5. End respectfully if agreement isn't reached\. 

__16\. Partnership Principles__

Project UIL may collaborate with organisations that align with its mission\.

Potential partners should demonstrate:

- Ethical conduct 
- Respect for users 
- Interest in research 
- Commitment to accessibility or human\-centred design 

__17\. Community Growth__

A strong community is built through:

- Trust 
- Consistency 
- Respect 
- Useful research 
- Open discussion 

Not through controversy or sensationalism\.

__18\. Final Principle__

__Every interaction should leave people feeling respected, informed, and encouraged to think more deeply about human problems\.__
