# KNOWN ISSUES

> A living troubleshooting guide for the UIL project.
>
> **Every AI agent must update this file whenever a new issue, failure, or recovery procedure is discovered.**
>
> The purpose is to ensure that the same problem is solved only once.

---

# Rules

Whenever you encounter a problem that required investigation:

* Add it here.
* Explain the root cause.
* Document the permanent solution.
* Include prevention steps.
* Update an existing entry if the problem evolves.
* Never delete useful historical knowledge.

---

